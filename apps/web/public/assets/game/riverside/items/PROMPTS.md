# Riverside item icon generation

Generated with the built-in `image_gen` tool on 2026-09-27. The supplied
`ref/thai-riverside-concept-v2.png` image was used only as a palette, material,
and lighting reference.

Each generated sheet was 1254 x 1254 pixels. The four 627 x 627 cells were
extracted in row-major order with the existing `sharp` package. Runtime PNGs
are optimized for mobile: ordinary items are 128×128; framed card drops are
256×256 so the large reward moment stays crisp. Files remain palette-optimized.
The empty fourth cell in sheet 6 was not exported. No new dependency was added.
