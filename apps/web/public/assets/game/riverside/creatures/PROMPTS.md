# Riverside creature prompts

Generated with the built-in `image_gen` tool. The source PNGs were generated at 1254×1254 with alpha, then resized with Lanczos filtering to their runtime dimensions.

Mobile runtime textures are 192×192 for regular creatures and 360×360 for bosses; the game scales them to the existing logical-stage display sizes.
