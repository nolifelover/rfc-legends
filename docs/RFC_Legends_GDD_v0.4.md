## 1. ภาพรวมเกม (Game Overview)

### 1.1 Concept

**RFC Legends** คือเกม **Idle MMORPG** ธีมไก่ชนไทย ผู้เล่นรับบทเป็น "นายไก่" ออกผจญภัยพร้อม **ไก่คู่หู** ที่เดินตามและสู้เคียงข้างตลอดเวลา ตัวละครและไก่เก็บเลเวลไปด้วยกันแม้ผู้เล่นจะปิดแอป ส่วนเวลาที่ผู้เล่นเปิดแอปใช้ไปกับการตัดสินใจ การพัฒนาตัวละคร การทำฟาร์ม และการพูดคุยกับ Party และค่ายไก่ (Guild)

เกมเชื่อมกับ **RWA ไก่ชนตัวจริง** ที่ RFC Club ขาย โดยมีนิลนีย์ฟาร์มเป็นผู้ดูแลตัวจริง ผู้เล่นใช้ได้ทั้งการ์ดไก่จริง (RWA Card) และการ์ดไก่ในเกม (Virtual Card) ภายใต้ระบบเดียวกัน

### 1.4 Core Loop

**Loop สั้น (ทุกครั้งที่เปิดแอป):** รับรางวัล Idle → แจกแต้ม Stat/Skill → เปลี่ยนอุปกรณ์/เสียบการ์ด → เก็บเกี่ยวฟาร์ม ทำอาหารไก่ → เลือกแผนที่ใหม่ → คุยใน Chat → ปิดแอป

**Loop กลาง (รายวัน):** Guild Boss → Arena Card Battle → Daily Quest → ผสมพันธุ์ไก่ → เปิดร้าน Vending

**Loop ยาว (รายสัปดาห์/Season):** ศึกชิงสนาม → เปลี่ยนอาชีพขั้น 2 → ล่า MVP Boss → สะสมการ์ดครบ Dex → Battle Pass → ซื้อหรือผสมพันธุ์กับ RWA

### 2.2 Stat หลัก 6 ค่า (แจกแต้มเอง)

|          |                                   |                                |
| -------- | --------------------------------- | ------------------------------ |
| **Stat** | **ผลต่อตัวละคร**                  | **ผลต่อไก่คู่หู (Link Bonus)** |
| STR      | ATK +2/แต้ม, น้ำหนักแบกของ        | พลังไก่ +0.2/แต้ม              |
| AGI      | FLEE +1, ความเร็วโจมตี (ASPD)     | ความเร็วไก่ +0.2/แต้ม          |
| VIT      | HP +10, DEF +1, ทนสถานะผิดปกติ    | ความอึดไก่ +0.2/แต้ม           |
| INT      | SP +4, พลัง Skill +2, ลด Cooldown | ระยะเวลา Buff ที่ให้ไก่ +1%    |
| DEX      | HIT +1, ATK +0.2, ลดเวลาร่าย      | เชิงไก่ +0.2/แต้ม              |
| LUK      | CRIT +0.3%, อัตราดรอป +0.1%       | ใจสู้ไก่ +0.2/แต้ม             |

**กติกาแต้ม:** เริ่มที่ Lv1 มี 48 แต้ม ทุก Stat เริ่มที่ 1 ขึ้นเลเวลได้ 3 + floor(Lv/5) แต้ม ค่าใช้แต้มเพื่อเพิ่ม Stat จาก x เป็น x+1 = 2 + floor((x−1)/10) Stat สูงสุด 99

> Balance: ที่ Lv99 ผู้เล่นมีแต้มรวม 1,273 แต้ม ส่วนการดัน Stat หนึ่งค่าจาก 1 ถึง 99 ใช้ 628 แต้ม จึงดันสุดได้ราว 2 ค่า ผู้เล่นต้องเลือก Build (แบบเดียวกับ RO) และมี Auto-Allocate ตาม Build Template ให้คนที่ไม่อยากคิดเอง

## 3. ไก่คู่หู (Companion Rooster)

นายไก่แต่ละคนพาไก่ออกสู้ได้ **1 ตัว** (ปลดล็อกเป็น 2 ตัวใน Job ขั้น 2) ไก่เดินตามในแผนที่ สู้อัตโนมัติ และได้ EXP 60% ของ EXP ที่นายไก่ได้ ส่วนไก่ที่ไม่ได้ออกสู้อยู่ในเล้า และเก็บ EXP ได้ผ่านคอกซ้อม (ดูหมวดฟาร์ม)

### 3.1 Stat ของไก่

|                |                                                                        |
| -------------- | ---------------------------------------------------------------------- |
| **Stat**       | **ผล**                                                                 |
| พลัง (POW)     | ATK ไก่ = POW×2.5 + เชิง                                               |
| ความเร็ว (SPD) | ความถี่การโจมตีและโอกาสได้เริ่มก่อนใน Arena                            |
| ความอึด (STA)  | HP ไก่ = 80 + STA×12, ฟื้นตัวเร็ว                                      |
| เชิง (TEC)     | CRIT และโอกาสเกิด Combo                                                |
| ใจสู้ (SPR)    | ต้านอาการกลัว/มึน และเมื่อ HP ต่ำกว่า 30% ได้บัฟ "ใจไม่ถอย" (ATK +25%) |

### 3.2 สายพ่อพันธุ์ (Bloodline Class)

ตั้งต้นจากพ่อพันธุ์ 5 สายของนิลนีย์ฟาร์ม สายเลือดเป็นตัวกำหนดอัตราการโตของ Stat และ Signature Skill

|            |                       |                      |                                                    |
| ---------- | --------------------- | -------------------- | -------------------------------------------------- |
| **สาย**    | **บุคลิก**            | **Stat เด่น**        | **Signature Skill**                                |
| กุมารจีน   | คม ฉลาด อ่านเกมเก่ง   | เชิง ++, ความเร็ว +  | เชิงคมกริบ: ตี 3 ครั้ง ครั้งสุดท้าย CRIT แน่นอน    |
| คิงคอง     | โครงใหญ่ สมดุลดี      | พลัง ++, ความอึด +   | ร่างยักษ์: รับดาเมจแทนนายไก่ 50% นาน 10 วินาที     |
| เจ้าขุนทอง | ลีลางาม สง่า          | สมดุลทุกค่า, ใจสู้ + | ลีลาทอง: บัฟ ATK/FLEE ทั้ง Party +10%              |
| เทพบุตร    | อึด ทน สู้ไม่ถอย      | ความอึด ++, ใจสู้ ++ | ใจเหล็ก: ไม่ตาย 1 ครั้งต่อการสู้ (ค้าง HP 1)       |
| แร๊พเตอร์  | ชั้นเชิงดุดัน รวดเร็ว | ความเร็ว ++, เชิง +  | เชิงพญาเหยี่ยว: พุ่งตีข้ามแนว 250% โดนศัตรูแถวหลัง |

> ทีมเป็นตัวแทนของนิลนีย์ฟาร์ม ใช้ชื่อสายพ่อพันธุ์ในเกมได้ ควรเก็บหนังสือยืนยันสิทธิ์ไว้เป็นเอกสาร

## 4. ระบบ Idle Combat

### 4.1 หลักการ

  - ผู้เล่นเลือก **แผนที่** ที่จะไปล่า นายไก่กับไก่เดินหาและสู้มอนสเตอร์เองตลอดเวลา

  - ทุกการคำนวณเกิดที่ Server (Server-authoritative) Client มีหน้าที่แค่แสดงผล

  - **Online:** ใช้ Simulation แบบเต็ม เห็นการสู้ ดาเมจ และของดรอปแบบ Real-time

  - **Offline:** ใช้ Rate-based Settlement คำนวณจากพลังตัวละครเทียบกับแผนที่ ได้ EXP/ของ 70% ของอัตรา Online ตั้ง Cap ไว้ 12 ชม. (ขยายได้ถึง 16 ชม. ด้วย Guild Skill)

### 4.2 Auto-Strategy (ผู้เล่นตั้งครั้งเดียว)

|                |                                               |

## 8. ฟาร์ม (Harvest Moon Style)

### 8.1 ปฏิทินและฤดูกาล

1 วันในเกมเท่ากับ 1 วันจริง มี 3 ฤดูแบบไทย ฤดูละ 10 วันจริง (ร้อน → ฝน → หนาว) ทุกฤดูมีพืชที่ได้ผลผลิตดีขึ้นเป็นพิเศษ และมีเทศกาลประจำฤดู

### 8.2 พืช

|            |            |                    |                        |
| ---------- | ---------- | ------------------ | ---------------------- |
| **พืช**    | **เวลาโต** | **ฤดูที่ได้โบนัส** | **ใช้ทำ**              |
| ข้าวเปลือก | 2 ชม.      | ฝน                 | อาหารไก่พื้นฐาน        |
| ถั่วเขียว  | 3 ชม.      | ร้อน               | อาหารเพิ่มพลัง         |
| ข้าวโพด    | 4 ชม.      | ร้อน               | อาหารเร่งโต            |
| ตะไคร้     | 6 ชม.      | ฝน                 | ยาอาบไก่ (ฟื้นความอึด) |
| ขมิ้น      | 8 ชม.      | หนาว               | ยาต้ม (ฟื้น HP)        |
| ไพล        | 12 ชม.     | หนาว               | ยาทาพิเศษ (ต้านสถานะ)  |

### 8.4 สูตรอาหารและยา (ตัวอย่าง)

### 8.5 NPC ชาวบ้าน

ชาวบ้านมีค่าความสัมพันธ์ 0–10 หัวใจ เพิ่มจากการให้ของและทำ Quest เมื่อสนิทกันแล้วจะปลดล็อกสูตรลับ ร้านพิเศษ และเนื้อเรื่องของตัวละครนั้น เช่น ลุงเซียนไก่ประจำหมู่บ้าน, ป้าร้านยาสมุนไพร, ช่างตีเหล็ก

  - **ช่วยเหลือเพื่อน:** เข้าไปเยี่ยมฟาร์มเพื่อนเพื่อรดน้ำให้ได้วันละ 5 ครั้ง ทั้งสองฝ่ายได้รางวัล

## 9. การผสมพันธุ์และพันธุกรรม

### 9.1 Gene

ไก่ทุกตัวมี **Gene (ศักยภาพ) 0–31** ในแต่ละ Stat เป็นตัวกำหนดเพดานการโต ผู้เล่นทั่วไปเห็นเป็นเกรด (D/C/B/A/S) ส่วนอาชีพนักผสมพันธุ์เห็นเป็นตัวเลขจริง

|            |                                                                                    |
| ---------- | ---------------------------------------------------------------------------------- |
| **กฎ**     | **รายละเอียด**                                                                     |
| Gene ลูก   | ค่าเฉลี่ยของพ่อแม่ ±3 (สุ่ม)                                                       |
| กลายพันธุ์ | โอกาส 3% ที่ Gene หนึ่งค่า +5 (เซียนสายเลือดได้ 6%)                                |
| สายเลือด   | ลูกได้สายของพ่อ ค่าความบริสุทธิ์ = (บริสุทธิ์พ่อ + บริสุทธิ์แม่ถ้าสายเดียวกัน) / 2 |
| สีขน       | ถ่ายทอดตามตาราง Dominance ที่ออกแบบไว้ มีโอกาสเล็กน้อยได้สีหายาก                   |
| Cooldown   | แม่พันธุ์ 24 ชม. ต่อครั้ง, พ่อพันธุ์ Virtual 12 ชม.                                |

### 9.2 Digital Stud (ผสมพันธุ์กับพ่อพันธุ์ RWA)

  - ผู้เล่นพาแม่ไก่ Virtual มาผสมกับพ่อพันธุ์ RWA ได้ โดยจ่าย Stud Fee

  - ลูกที่ได้เป็น **Virtual Card** ที่มีสายเลือดพ่อพันธุ์จริงบันทึกใน Pedigree และมีโอกาสได้ Signature Skill ของสาย

  - จำกัดสัปดาห์ละ 5 ครั้งต่อพ่อพันธุ์ RWA หนึ่งตัว เพื่อรักษาความหายาก

  - **Stud Fee:** เข้าผู้ถือ RWA เต็มจำนวน

  - ค่าดูแลไก่จริงเป็น Package ของนิลนีย์ฟาร์ม อยู่นอกขอบเขตของเกม

## 10. RWA Card กับ Virtual Card

|              |                                                                                               |                                                  |
| ------------ | --------------------------------------------------------------------------------------------- | ------------------------------------------------ |
|              | **RWA Card (ไก่จริง)**                                                                        | **Virtual Card (ไก่ในเกม)**                      |
| ที่มา        | RFC Club ขาย นิลนีย์ฟาร์มดูแลตัวจริง                                                          | ฟักไข่, ดรอป, ผสมพันธุ์, รางวัล                  |
| จำนวน        | จำกัด 1 การ์ด = ไก่ 1 ตัว                                                                     | ไม่จำกัด                                         |
| Stat ตั้งต้น | จากข้อมูลจริง (สาย, น้ำหนัก, อายุ) แปลงตามสูตร                                                | สุ่มจาก Gene ของพ่อแม่                           |
| การอัปเดต    | ฟาร์ม Sign ข้อมูลจริงเข้ามาทุกสัปดาห์                                                         | เปลี่ยนตามการเลี้ยงในเกม                         |
| Rarity       | Mythic + Verified Badge                                                                       | Common ถึง Legendary                             |
| สิทธิพิเศษ   | ดูกล้องสดตัวจริง, Digital Stud, ท่าพิเศษประจำสาย                                              | –                                                |
| Onchain      | ใช่ + ENS Name (Hackathon: Contract ใหม่บน Sepolia; Production: เชื่อม RWA ทุก Chain ของ RFC) | Offchain เป็นค่าเริ่มต้น เลือก Mint เป็น NFT ได้ |

### 10.1 ข้อมูลที่ RWA Card ต้องมี

  - รหัสประจำตัวไก่ (ห่วงขา / Microchip), รูปและวิดีโอ, สายพ่อพันธุ์, สีขน, วันเกิด

  - Pedigree: พ่อ แม่ ปู่ย่า (ถ้าเป็น RWA ด้วยจะลิงก์ถึงกันผ่าน ENS)

  - Farm Attestation รายสัปดาห์: น้ำหนัก, สุขภาพ, วัคซีน, วันที่ตรวจ Sign โดย Key ของเจ้าหน้าที่นิลนีย์

  - ค่าดูแลไก่จริงเป็น Package ของนิลนีย์ฟาร์ม (นอกขอบเขตเกม)

  - สถานะประกัน (เชื่อมกับประกันของฟาร์ม), สถานที่เลี้ยงปัจจุบัน

### 10.2 Lifecycle

|                                        |                                                                               |
| -------------------------------------- | ----------------------------------------------------------------------------- |
| **เหตุการณ์จริง**                      | **ผลในเกม**                                                                   |
| ไก่โตขึ้น                              | การ์ดเปลี่ยนช่วงวัยตามอายุจริง                                                |
| ฟาร์มอัปเดตน้ำหนัก/สุขภาพ (รายสัปดาห์) | Stat ปรับตามสูตรแปลงข้อมูล (ต้องมีเพดานไม่ให้แกว่งแรง)                        |
| ไก่จริงมีลูก                           | ออก RWA Card ใบใหม่ ผูก Pedigree อัตโนมัติ                                    |
| ขายต่อ / เปลี่ยนเจ้าของ                | โอนการ์ด ตัวไก่ยังอยู่ที่ฟาร์ม (หรือขอรับตัว = Redeem)                        |
| ไก่ตาย                                 | การ์ดเป็นสถานะ Legacy เข้าหอเกียรติยศ ใช้ใน Arena ได้ต่อแต่ไม่มี Digital Stud |

### 10.3 Balance ระหว่าง 2 โหมด

  - Ranked ใช้ Stat แบบ Normalize ความได้เปรียบของ RWA อยู่ที่ Signature Skill, ชื่อเสียง, สายเลือด และรายได้จาก Stud ไม่ใช่พลังดิบ

  - Virtual กลายเป็น RWA ไม่ได้ ยกเว้นมีไก่จริงเกิดจากฟาร์มแล้วมาลงทะเบียน

  - ผู้เล่นที่ไม่ซื้อ RWA ต้องเล่นได้ครบทุกระบบ RWA เป็นทางเลือกสำหรับนักสะสม

## 12. AI ผู้ช่วยนายไก่ (AI Agent)

AI Agent ดูแลตัวละครแทนผู้เล่นตอน Offline ทำงานภายใต้ขอบเขตที่ผู้เล่นกำหนด

|                                             |                                           |
| ------------------------------------------- | ----------------------------------------- |
| **ทำได้เอง**                                | **ต้องให้คนจริงยืนยันด้วย World ID ก่อน** |
| ปรับ Auto-Strategy และเลือกแผนที่ที่คุ้มสุด | ซื้อ/ขาย RWA Card                         |
| ขายของดรอปในช่วงราคาที่ตั้งไว้              | จ่าย Stud Fee กับ RWA                     |
| จัด Deck Arena ตาม Meta                     | โอนไอเทมหรือเงินมูลค่าเกิน Limit ต่อวัน   |
| ปลูก/เก็บเกี่ยว/ทำอาหาร                     | ออกจากค่ายหรือยุบค่าย                     |
| สรุปรายงานประจำวันส่งเข้า Chat              | เปลี่ยนกระเป๋าเงินที่ผูกกับบัญชี          |

  - เมื่อ Agent จะทำ Action ที่มีความเสี่ยง จะส่ง Request ให้เจ้าของ → เจ้าของ Verify ด้วย World ID → Backend Validate → จึงทำ Action ได้ ถ้าไม่ยืนยันหรือหมดเวลา Action จะถูกยกเลิก

  - ก่อนจ่ายเงินทุกครั้งต้องผ่านการตรวจ Payment Screening (Intercepta) ด้วย

### 13.2 Faucet และ Sink

|                             |                                                |
| --------------------------- | ---------------------------------------------- |
| **ไหลเข้า (Faucet)**        | **ไหลออก (Sink)**                              |

### 13.3 รายได้ของ RFC Club

RFC Club หัก **10% จากทุกการขายใน Rare Market** ได้แก่ ของดรอประดับ Legendary, Monster Card, MVP Card, ไข่เกรดสูง, การขายต่อ RWA Card และลูกไก่ที่หายาก ของดีต้องเกิดจากการเล่นเท่านั้น ยิ่งมีคนเล่นมาก ของก็ถูกผลิตและซื้อขายมาก รายได้จึงโตตามจำนวนผู้เล่น

> World ID บังคับ 1 คน = 1 บัญชีหลัก เพื่อกันการเปิดหลายบัญชีฟาร์มของ ซึ่งเป็นปัญหาใหญ่ที่สุดของเกม Idle และคือสิ่งที่รักษาเศรษฐกิจในเกมไว้

## 15. Technical Architecture

|               |                               |                                                               |
| ------------- | ----------------------------- | ------------------------------------------------------------- |
| **Layer**     | **เทคโนโลยีที่แนะนำ**         | **หมายเหตุ**                                                  |
| Client        | Next.js (PWA) + Phaser 3      | Phaser ใช้ Render ฉาก Isometric ส่วน UI เป็น React            |
| Game Server   | Node.js / TypeScript          | Tick Worker จำลองการสู้, Rate-based Settlement สำหรับ Offline |
| Database      | PostgreSQL (Supabase)         | ข้อมูลผู้เล่น ไอเทม ไก่ Guild                                 |
| Realtime      | Supabase Realtime / WebSocket | Chat, Party, Live Replay                                      |
| Cache / Rank  | Redis                         | Leaderboard, Session, Rate Limit                              |
| Chain Indexer | Indexer ของ RWA + ENS Events  | Sync สถานะการ์ดจริงเข้าเกม                                    |
| Battle Engine | Deterministic + Seed          | ผลเหมือนเดิมทุกครั้ง ใช้เป็น Replay และตรวจโกงได้             |
| LiveOps       | Admin Panel + Analytics       | ตั้ง Event, ปรับค่า Balance, ดู Funnel                        |

  - **Anti-cheat:** คำนวณทุกอย่างที่ Server; Client ส่งแค่คำสั่ง; ตรวจ Rate ของ EXP/ดรอปผิดปกติ

  - **Scaling:** เกม Idle ไม่ต้อง Sync ตำแหน่ง Real-time ระหว่างผู้เล่น ทำให้รองรับผู้เล่นจำนวนมากได้ด้วยต้นทุนต่ำกว่า MMORPG ปกติ

## 16. Art, Audio และ Content

  - **Art Direction:** Chibi 2.5D สีสด ท้องทุ่งไทย ไก่ดูน่ารักแต่มีบุคลิกชัดเจน ไม่มีเลือด ไม่มีภาพบาดเจ็บ

  - **Pipeline:** ใช้ AI Generate Concept Art และ Sprite ต้นแบบ แล้วให้ Artist Cleanup และทำ Animation เพื่อให้สไตล์ทั้งเกมเหมือนกัน

  - **Asset ที่ต้องมี:** ตัวละคร 9 อาชีพ × ชาย/หญิง, ไก่ 5 สาย × 5 สี, มอนสเตอร์ \~40 ตัว + MVP 6 ตัว, Tileset 6 แผนที่ + เมือง + ฟาร์ม, Icon ไอเทม/การ์ด

  - **Audio:** ดนตรีพื้นบ้านไทยผสมแนว Lo-fi (แคน, ระนาด, พิณ) และเสียงไก่ขันเป็นเอกลักษณ์

  - **เนื้อเรื่อง:** นายไก่มือใหม่ได้รับไข่ใบแรกจากลุงเซียนไก่ แล้วออกเดินทางไปป่าหิมพานต์เพื่อตามหาต้นสายพันธุ์ไก่ในตำนาน

### 22.3 การ์ดแบบถาวร + Set Bonus

ที่มา: RO ดรอปการ์ด 0.01% ต่อตัว อาวุธมี Slot ได้ถึง 4 ช่อง อุปกรณ์อื่นมี 1 ช่อง เสียบแล้วเป็นของถาวร มี Combo เมื่อใส่การ์ดบางชุดพร้อมกัน และการ์ดบางใบให้ Skill ที่อาชีพนั้นไม่มี

  - **Compound ถาวร:** เสียบแล้วการ์ดหายออกจากตลาด ผู้เล่นต้องหาใบใหม่ทุกครั้งที่ทำ Build ใหม่ ทำให้ Rare Market มีคนซื้อตลอด

  - **Slot ไม่เท่ากัน:** อาวุธ 0–4 Slot (อาวุธ 4 Slot หายากมากและมีราคาสูง), อุปกรณ์อื่น 0–1 Slot, อุปกรณ์ไก่ 1 Slot

  - **Set Bonus:** เช่น การ์ดพังพอน + การ์ดงูเขียว = "ศัตรูคู่ปรับ": ดาเมจต่อสัตว์เลื้อยคลาน +15% เพิ่ม ทำให้การ์ดธรรมดาบางใบมีราคาเพราะเป็นชิ้นหนึ่งของ Set

  - **การ์ดให้ Skill:** เช่น การ์ดนกเค้า ทำให้อาชีพไหนก็ได้ใช้ "ตาเหยี่ยว" (มองเห็นมอนสเตอร์ล่องหน)

  - **ถอดการ์ด:** NPC ถอดได้ด้วยเบี้ยจำนวนมาก และมีโอกาส 30% ที่การ์ดจะเสียหาย (เป็น Sink)

### 22.5 คุณสมบัติสุ่ม (Random Option) และ Enchant

  - อุปกรณ์ที่ดรอปจาก Rare ขึ้นไปมีคุณสมบัติสุ่ม 0–3 บรรทัด เช่น "ATK +3%", "ดาเมจต่อธาตุไฟ +5%" ทำให้ของชื่อเดียวกันมีมูลค่าไม่เท่ากัน

### 22.10 ความหลากหลายของ Build

  - **เผ่าและขนาดของมอนสเตอร์:** สัตว์ปีก / สัตว์เลื้อยคลาน / สัตว์สี่เท้า / สัตว์ตำนาน × ขนาดเล็ก/กลาง/ใหญ่ มีการ์ดและอาวุธที่แรงกับเผ่าหรือขนาดเฉพาะ ผู้เล่นจึงต้องมีชุดอุปกรณ์หลายชุดสำหรับแต่ละแผนที่

  - **ระดับธาตุ 1–4:** มอนสเตอร์ระดับธาตุสูงแพ้/ชนะธาตุรุนแรงขึ้น ทำให้ต้องเปลี่ยนสีไก่คู่หูตามแผนที่

  - **รีเซ็ต Stat/Skill:** ทำฟรี 1 ครั้งตอนเปลี่ยนอาชีพขั้น 2 หลังจากนั้นเสียเบี้ยหรือต้องใช้ไอเทมดรอป เพื่อให้คนกล้าลอง Build ใหม่แต่ไม่ทำบ่อยจนไม่มีค่า

  - **ตายแล้วเสีย EXP เล็กน้อย:** Idle หยุดและเสีย EXP 1% ของเลเวลนั้น (ไม่ทำให้ลดเลเวล) ผู้เล่นจึงมีเหตุผลที่จะตั้งกลยุทธ์ให้ดีและมีหมอไก่อยู่ใน Party

### 22.11 ต้องพึ่งกัน (Forced Interdependence)

บทความวิเคราะห์ว่า RO อยู่ได้นานเพราะผู้เล่นต้องขอบัฟ ขอฮีล และชวนคนแปลกหน้าเข้าปาร์ตี้ จนกลายเป็นมิตรภาพจริง เราจึงออกแบบให้:

  - **บัฟข้ามผู้เล่น:** หมอไก่และขุนพลค่ายบัฟผู้เล่นคนอื่นในเมืองได้ (มีผล 1 ชม. ตอน Idle) ผู้ให้บัฟได้ "แต้มน้ำใจ" ไปแลกของ ทำให้มีคนนั่งบัฟในเมืองเหมือน RO

  - **อาชีพที่ขาดบางอย่าง:** นักสู้ไม่มี Heal, หมอไก่ตีเบา, นักฟาร์มต้องพึ่งคนอื่นเรื่องการสู้แต่เป็นคนผลิตอาหารให้ทั้งค่าย

  - **Buying Store:** ตั้งร้านรับซื้อ (ไม่ใช่แค่ขาย) เช่น นักฟาร์มรับซื้อวัตถุดิบดรอป

  - **คู่หูสาบาน (แทนระบบแต่งงาน):** ผู้เล่น 2 คนผูกเป็นคู่ได้ มี Skill เรียกหากัน และบัฟเมื่ออยู่ Party เดียวกัน มีพิธีในเกมพร้อม Cosmetic

  - **ครู–ศิษย์:** แทนระบบรับเลี้ยง (Adoption) ครูได้รางวัลเมื่อศิษย์ผ่านแต่ละขั้น

### 22.12 งานช่างหมวกและแฟชั่น

ที่มา: RO มีภารกิจทำหมวกที่ใช้วัตถุดิบจำนวนมาก เช่น หมวกบางใบต้องใช้ Jellopy 10,000 ชิ้น ผู้เล่นทำเพื่อทั้งแฟชั่นและ Stat

  - หมวก/ชุดธีมไทย เช่น งอบลายทอง, หัวโขนจิ๋ว, ผ้าขาวม้าเทศกาล ใช้ของดรอปธรรมดาจำนวนมาก + วัตถุดิบฟาร์ม

  - ของดรอป Common จึงยังมีค่า คนเลเวลต่ำขายให้คนเลเวลสูงได้ ช่วยผู้เล่นใหม่มีรายได้

  - ระบบ Costume: เอารูปลักษณ์ไปใส่ทับอุปกรณ์ที่มี Stat ได้ (รายได้ Cosmetic)

### 22.13 Season Server

บทความวิเคราะห์ว่าวงจร Private Server ของ RO (เปิดใหม่ คนกลับมารวมตัว เริ่มจากศูนย์พร้อมกัน) คือเหตุผลหนึ่งที่เกมไม่ตาย เราทำเป็นระบบทางการ:

  - ทุก 4–6 เดือนเปิด Season Server ทุกคนเริ่มจาก Lv1 พร้อมกัน มี Leaderboard แข่งกันไปถึง 99 ก่อน

  - จบ Season ย้ายตัวละครเข้าเซิร์ฟเวอร์หลัก ได้ตำแหน่งและ Cosmetic ประจำ Season

  - RWA Card ใช้ได้ทุกเซิร์ฟเวอร์ (ไก่จริงเป็นของผู้ถือเสมอ)
