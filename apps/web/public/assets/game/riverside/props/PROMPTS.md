# Riverside prop prompts

Generated with the built-in `image_gen` tool. The source PNGs were generated at 1254×1254 with alpha, then resized with Lanczos filtering to 200×200.

For the mobile game runtime, each prop is further reduced to 128×128 with alpha; its display size remains controlled by the existing Phaser scene.
